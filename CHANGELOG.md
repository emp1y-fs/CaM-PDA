# Changelog

## 0.4.0

- Simplified the application to single-frame RGB-D inference; removed reference-view input, pose estimation and fusion.
- Added four calibrated engine-component examples from the manuscript to the source and installed package.
- Rewrote the English and Chinese guides around visual-to-sensor depth alignment, runtime input paths and reproducibility.
- Kept the CaM-PDA model weights, single-frame numerical pipeline and output file formats unchanged.

Earlier application versions remain available in Git history and their tagged releases.
